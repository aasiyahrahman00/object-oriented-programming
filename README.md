# Object-Oriented Programming Python Projects

This repository contains Python projects and formative activities completed as part of my Object-Oriented Programming module.

The work was developed to practise object-oriented programming concepts including classes and objects, inheritance, polymorphism, encapsulation, abstraction, design patterns, exception handling and unit testing.

## Contents

### Formative Activities

The Unit 1–9 folders contain Python exercises and practical activities covering:

- classes and objects
- inheritance and polymorphism
- encapsulation and abstraction
- exception handling
- design patterns
- modularisation
- testing and debugging

These activities helped develop my understanding of object-oriented software design before applying the concepts to larger assessment tasks.

## Mid-Module Assessment - Online Shopping System

The application includes:

- product and stock management
- shopping basket functionality

- order placement and tracking
- input validation
